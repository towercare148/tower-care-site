# Building Harmony

Build a complete, premium, modern Hebrew RTL website for a professional building cleaning company.

The company specializes specifically in recurring cleaning and maintenance of residential buildings, apartment complexes, office buildings, shared spaces and building common areas.

The website should NOT feel like a generic house-cleaning company.

The main target audience is:

ועד בית

חברות ניהול ואחזקה

מנהלי נכסים

בנייני מגורים

מגדלי מגורים

בנייני משרדים

קבלנים / יזמים המחפשים שירות ניקיון קבוע

LANGUAGE:
Hebrew only.
Full RTL layout.
All UI elements, forms, buttons and navigation must work correctly in RTL.

STYLE / BRAND DIRECTION:
Create a premium, trustworthy and extremely clean visual identity.

The website should communicate:

סדר

ניקיון

אמינות

שירות קבוע

אחריות

מקצועיות

שקט לוועד הבית / מנהל הבניין

Do not make the design look cheap or like a small local cleaning flyer.

Use:

Large typography

Lots of whitespace

Clean layouts

Modern cards

Subtle animations

Premium photography of modern apartment buildings, clean lobbies, staircases, elevators and shared areas

Strong mobile responsiveness

Avoid:

Cartoon cleaning icons

Too many gradients

Cheap stock-photo feeling

Overuse of blue cleaning bubbles

Crowded layouts

IMPORTANT UX RULE

The main conversion goal of the entire website is:

Getting a building committee member, property manager or management company to either:

Submit the quote form
OR

Start a WhatsApp conversation.

Every major section should naturally guide the user toward one of those actions without being overly aggressive.

The website should feel like a serious service company capable of managing ongoing cleaning contracts, not an individual cleaner offering hourly cleaning.
